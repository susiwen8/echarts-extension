# @echarts-extension/evolution-fluid

Language: English | [中文](./README_CN.md)

ECharts extension chart for event-driven entity-point evolution maps. Import this package for side effects to register `series.type = 'evolutionFluid'`.

![Evolution Fluid chart](../../visual-baseline/echarts-evolution-fluid.png)

## Install

```bash
npm install echarts @echarts-extension/evolution-fluid
```

## Basic Usage

```js
import * as echarts from 'echarts';
import '@echarts-extension/evolution-fluid';

const chart = echarts.init(document.getElementById('main'));

chart.setOption({
  series: [
    {
      type: 'evolutionFluid',
      entities: [
        { id: 'alpha', name: 'Alpha AI', industry: 'AI', value: 120 },
        { id: 'beta', name: 'Beta Cloud', industry: 'Cloud', value: 80 },
        { id: 'media', name: 'Media Lab', industry: 'Media', value: 42 }
      ],
      events: [
        { time: '2019', type: 'found', targets: ['alpha'], value: 120 },
        { time: '2021', type: 'acquire', sources: ['beta'], targets: ['alpha'], value: 45 },
        { time: '2024', type: 'spinOff', sources: ['alpha'], targets: ['media'], value: 20 }
      ],
      currentTime: '2024',
      dropletStyle: {
        bridgeThreshold: 240,
        bridgeOpacity: 0.78
      }
    }
  ]
});
```

## Data

`entities` describes long-lived points such as companies, industries, or business units. Each rendered point is one entity. `events` describes how those points approach, merge, absorb, split, rename, close, or connect over time.

- `found` fades a point into the timeline.
- `acquire` and `merge` draw source-to-target metaball bridges.
- `split` and `spinOff` draw separating bridge relationships.
- Custom event types use the same `sources` and `targets` shape and are drawn as generic point transitions.
- Missing entity ids referenced by events are converted into placeholder points so incomplete story data still renders.

### Experimental Fluid Simulation

Set `fluidSimulation.enabled` to `true` to route acquire, merge, split, and spin-off frames through the deterministic implicit-surface runtime. The existing renderer remains the default while the new runtime is being visually tuned.
