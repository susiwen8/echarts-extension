# @echarts-extension/algorithm-shortest-path

ECharts extension chart for shortest path algorithm visualization. Import this package for side effects to register `series.type = 'algorithmShortestPath'`.

## Usage

```ts
import * as echarts from 'echarts';
import '@echarts-extension/algorithm-shortest-path';

const chart = echarts.init(document.getElementById('chart'));
chart.setOption({
  series: [
    {
      type: 'algorithmShortestPath',
      algorithm: 'dijkstra',
      start: 'A',
      target: 'F',
      currentStep: 12,
      nodes: [
        { id: 'A', x: 0.08, y: 0.5 },
        { id: 'B', x: 0.25, y: 0.25 },
        { id: 'F', x: 0.9, y: 0.45 }
      ],
      edges: [
        { source: 'A', target: 'B', weight: 2 },
        { source: 'B', target: 'F', weight: 5 }
      ]
    }
  ]
});
```

## Algorithms

The first release covers Dijkstra, BFS, A* search, and Bellman-Ford. The series generates deterministic frames internally; change `currentStep` or `progress` to scrub through visits, edge inspections, relaxations, and the final path.
