# @echarts-extension/seasonal-radial

Language: English | [中文](./README_CN.md)

ECharts extension chart for seasonal radial small multiples. Import this package for side effects to register `series.type = 'seasonalRadial'`.

![Seasonal Radial chart](../../visual-baseline/echarts-seasonal-radial.png)

## Install

```bash
npm install echarts @echarts-extension/seasonal-radial
```

## Basic Usage

```js
import * as echarts from 'echarts';
import '@echarts-extension/seasonal-radial';

const chart = echarts.init(document.getElementById('main'));

chart.setOption({
  backgroundColor: '#000',
  series: [
    {
      type: 'seasonalRadial',
      data: [
        { country: 'Spain', year: 2025, month: 'Jan.', value: 2.2 },
        { country: 'Spain', year: 2025, month: 'Feb.', value: 3.1 },
        { country: 'Spain', year: 2025, month: 'Mar.', value: 4.4 },
        { country: 'Germany', year: 2025, month: 'Jan.', value: 2.4 },
        { country: 'Germany', year: 2025, month: 'Feb.', value: 4.1 },
        { country: 'Germany', year: 2025, month: 'Mar.', value: 7.2 }
      ],
      groupField: 'country',
      yearField: 'year',
      monthField: 'month',
      valueField: 'value',
      groups: ['Spain', 'Germany'],
      min: 0,
      max: 10,
      highlightYear: 2025
    }
  ]
});
```

## Data

Use objects or array rows:

- `groupField` splits the chart into small-multiple radial panels.
- `yearField` groups records into one seasonal track per year.
- `monthField` orders records around the circle. Set `months` for explicit month labels and order.
- `valueField` maps each month to radial distance.
- Set `dimensions` when using array rows.
